# SK-001 · 夜雨城（Night Rain City）

**通俗名称：** 三维城市生成工具包。

**它能做什么：** 用 Three.js 创建可以在浏览器里走动的三维夜间城市。提供建筑、街道、玻璃楼宇、灯牌、雨雪/天气相关基础模块、人物、店铺、广场、地铁等可配置部件。原始 Skill 视觉基调为蓝青色夜雨城市，不是圣诞雪景模板。

**准确来源：** https://github.com/Hyraland/night-rain-city-skill
- 安装/使用说明：https://github.com/Hyraland/night-rain-city-skill/blob/main/SKILL.md
- 原始引擎代码：https://github.com/Hyraland/night-rain-city-skill/tree/main/engine
- 技术/权限：Three.js；原仓库标注 MIT，复用时保留第三方版权与许可。

**已应用的作品：**《第二个圣诞夜》（历史源码内部也写作《第十二个圣诞夜》）。
- 作品仓库：https://github.com/velunelle/the-second-christmas-night
- 当前版本：https://github.com/velunelle/the-second-christmas-night/tree/main/versions/current
- 上一个版本：https://github.com/velunelle/the-second-christmas-night/tree/main/versions/previous
- 当前版源码示例：[城市街区定义](https://github.com/velunelle/the-second-christmas-night/blob/main/versions/current/dist/src/district.js)；[核心引擎与场景模块](https://github.com/velunelle/the-second-christmas-night/tree/main/versions/current/dist/src/kit)；[天气模块](https://github.com/velunelle/the-second-christmas-night/tree/main/versions/current/dist/src/core)。
- 已证实的项目改编：圣诞主题、雪夜与雨夜切换、3D 城市漫游、镜头与场景系统。具体每项实现仍应读取该版本的真实源码，不因 Skill 名称就假定具备全部功能。

**下次怎么用（节省 token）：**
1. 用户说「用 SK-001 夜雨城工具包」时，先打开本条目，再读官方 SKILL.md。
2. 若是继续《第二个圣诞夜》，先读现有仓库的 **current/previous** 版本及相关源码，保留用户认可的旧版，不直接创建新城市。
3. 若是全新城市项目，按官方 Skill 说明获取引擎，并另写自己的 district.js。注意官方示范布局不等于用户认可的实际设计。
4. 将项目源码与 Skill 区分：**源 Skill = 通用工具包；《第二个圣诞夜》= 基于该工具包做出的定制作品**。也不应自行添加下沉广场、地铁等没有在需求中确认的场景。
