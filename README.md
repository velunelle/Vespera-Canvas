## 使用规则

1. 先按资产编号查询对应源码，不重新搜索相同效果。
2. 原项目文件不覆盖；新项目通过导入或改编复用。
3. 动效只能根据实际代码标记为“已核实”，未发现的效果标记“需补做”，不得冒充已有。
4. 视觉验收需要实际播放/截图；文字只用于解释，不代替动效证据。
5. 人物头像的公开再分发授权未确认，本库不复制头像；已有截图或原游戏并不自动转授权。
