# SN-002-M · 雪晶迎面穿梭（已认可的运动效果）

**一眼能懂的名字：** 雪晶从远处向镜头飞来。

**用户确认认可的部分：** 手机端黑白雪晶的运动、由远及近的空间穿梭感。认可的是**动效与空间感**，不是整张画面的美术完成度。

**暂不认可的部分：** 纯黑背景缺少原视频那种有明暗层次、薄雾与空间空气感的黑；雪晶的纹理和材质偏图形化、缺少细腻的晶体氛围。后续提高画质时应保留运动轨迹、透视速度与近景掠过体验，单独改进背景与雪晶绘制，**不要从零重写已认可的运动系统**。

**源码位置：** [共享雪景引擎](../shared/snow-engine.js)，使用 `VesperaSnow.mount(canvas, { mode: 'white-tunnel', speed, density, seed })`。原效果见 [SN-002 完整示例](../SN-002-white-tunnel/index.html)。

**技术实现（已核对现有代码）：**
1. 雪晶和细小雪点各有三维空间参数 `x, y, z`；`z` 表示距离镜头的深度。
2. 随时间减少 `z`，模拟雪晶向镜头靠近；当 `z` 很小时，将其放回远方继续循环。
3. 投影时，屏幕位置用 `x/z`、`y/z` 计算，雪晶大小也按 `1/z` 增大。远处看起来小而密，近处更大、移动也更明显，形成从画面内部向四周扩散的穿梭错觉。
4. 技术是 **Canvas 2D 模拟三维透视**，不依赖 Three.js；近远雪点、雪晶按深度分别投影，在手机竖屏下使用独立宽高缩放。

**复用建议：** 全屏过场、进入雪夜场景、圣诞/冬季阅读背景、电影式穿越氛围。若只需要漫天缓缓落雪，不必直接套用这种明显向前穿梭的镜头效果。

**验收状态：** 运动部分已被用户认可；背景、雪晶美术待优化。作为可复用的**动效资产**保存，不把整套 SN-002 标记为最终审美通过。
